# 큐레이션 시드 작성·검수 기준

`data/flavor-seed.json`은 맛 정보가 있는 도감의 원본입니다. 위스키BTI 추천과 비슷한 위스키 추천은 모두 이 파일의 맛 벡터로 계산합니다.
이 문서는 새 위스키를 넣거나 기존 값을 고칠 때, 그리고 등급을 올릴 때의 기준입니다.

## 1. 레코드 규칙

| 필드 | 규칙 |
|---|---|
| `id` | `seed-<영문 소문자-하이픈>`. 한 번 정하면 바꾸지 않습니다(위시리스트·링크가 깨짐). |
| `name` | 영문 공식 표기. 숙성 연수와 에디션 이름까지 씁니다. |
| `nameKo` | 국내 수입사·판매처에서 흔히 쓰는 표기. |
| `distillery` | Wikidata 증류소 이름과 같은 영문 표기(좌표 연결에 씀). 블렌디드는 비웁니다. |
| `age` | 라벨의 숙성 연수. 표기가 없으면 `null`(NAS). |
| `abv` | 국내 정식 수입품 기준 도수. 캐스크 스트렝스는 대표 배치 값. |
| `price` | 국내 참고 가격(만원, 700ml). 판매 정보가 아니며 대략값. 국내에 700ml로 안 나오면 비웁니다. |
| `prices` | 그 밖의 용량·면세가. `{"ml":1000,"won":9.5,"where":"kr"}`(국내, 만원) 또는 `{"ml":1000,"usd":45,"where":"dutyfree"}`(면세, 달러). 450·500ml 국산 블렌디드도 여기에. |
| `dutyFree` · `trOnly` | 면세점에서 살 수 있으면 `dutyFree: true`, 면세점 전용(트래블 리테일 한정)이면 `trOnly: true`도. |
| `tags` | 대표 향 3개, 한국어. 아래 "향 태그 사전"의 표현을 우선합니다. |
| `summary` | 2줄 이내. 역사·유래 대신 맛과 특징. |
| `grade` | 처음에는 `C`(추정). §4 기준을 채우면 올립니다. |

## 2. 맛 벡터 10축 — 점수 기준점

각 축은 0~5, 0.5 단위까지 씁니다. **같은 축 안에서 상대 비교가 맞는지**가 절대값보다 중요합니다. 아래 기준 위스키와 나란히 놓고 점수를 정합니다.

| 축 | 0 | 2~3 | 5 |
|---|---|---|---|
| 단맛 | 드라이한 라이 | 글렌피딕 12년 | 메이커스 마크, 카발란 솔리스트 |
| 스모키·피트 | 피트 없음(대부분의 스페이사이드) | 보모어 12년, 하이랜드 파크 12년(2) | 라프로익 10년, 아드벡 10년 |
| 바디 | 가벼운 블렌디드 | 발베니 12년 | 아부나흐, 부커스 같은 고도수·셰리 |
| 스파이시 | 부드러운 블렌디드 | 우드포드 리저브 | 불렛 라이, 리튼하우스 라이 |
| 과일 | 피트·오크 위주 | 맥캘란 12년 셰리 오크 | 카발란 클래식(열대과일) |
| 꽃·허브 | 셰리·피트 위주 | 글렌리벳 12년 | 글렌모렌지 오리지널, 하쿠슈 |
| 몰티·곡물 | 버번·그레인 | 대부분의 싱글몰트 | 크라이겔라키, 딘스턴 |
| 오크·바닐라 | 젊은 몰트 | 숙성 12~15년 몰트 | 우드포드 더블 오크드, 장기 숙성 버번 |
| 견과·초콜릿 | 가벼운 몰트 | 발베니 더블우드 | 부나하벤 12년, 글렌드로낙 21년 |
| 셰리·와인 | 버번 캐스크만 | 더블 캐스크(셰리 일부) | 셰리 캐스크 100%(맥캘란 셰리 오크, 글렌드로낙) |

점검 규칙:
- **캐스크와 맞아야 합니다.** 셰리·와인·포트 통이 없으면 셰리·와인 축은 0~1입니다.
- **피트와 맞아야 합니다.** `peated: false`면 스모키는 0~1, `true`면 1 이상입니다.
- **미국 버번·라이·테네시는 오크 3 이상**입니다(새 오크 통 의무). 캐나다 라이는 해당하지 않습니다. 라이는 스파이시 4 이상이 기본입니다.
- **고도수(50% 이상)는 바디가 한 단계 높습니다.**
- **같은 브랜드의 상위 라인업**은 하위 라인업과 방향이 같고, 숙성·오크·바디가 같거나 높아야 자연스럽습니다.

## 4. 등급 올리기

| 등급 | 조건 |
|---|---|
| C 추정 | 시드 작성자 또는 AI가 넣은 값. 기본값. |
| B 커뮤니티 검증 | 서로 다른 사용자의 시음 기록 20건 이상에서 맛 슬라이더 평균과 축별 차이가 모두 1.0 이하. (v0.3 이후 시음 슬라이더 도입 시 자동 계산) |
| A 공식·검수 | 사람이 직접 시음했거나 공식 테이스팅 노트로 대조했고, §2 점검 규칙을 모두 통과. 검수자·날짜를 커밋 메시지에 남김. |

## 5. 작업 순서

1. `data/flavor-seed.json`에 한 줄씩 추가합니다(한 줄 = 한 위스키).
2. `npm test`: id 형식, 10축, 0~5 범위를 검사합니다.
3. `npm run sample`로 화면에서 비슷한 위스키 결과가 자연스러운지 몇 개 확인합니다.
4. 커밋하면 다음 주간 수집 때 바코드·증류소 좌표가 자동으로 붙습니다.
